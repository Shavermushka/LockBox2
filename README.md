# 🔒 LockBox2

![Alpha](https://img.shields.io/badge/Alpha-Проект-4D6BFE?style=for-the-badge&logo=github&logoColor=white) ![Arch Linux](https://img.shields.io/badge/Arch_Linux-Derivatives_✓_Tested-1793D1?style=for-the-badge&logo=archlinux&logoColor=white)


**Безопасное хранилище паролей с открытым исходным кодом**  
Локальное десктопное приложение на Python + PyQt6 с AES-256 шифрованием.

---

## ✨ Ключевые возможности

| Функция | Описание |
|---------|----------|
| 🔐 **Шифрование** | Мастер-пароль + PBKDF2 + Fernet (AES-256) |
| 📋 **Управление записями** | Название, логин, пароль, URL, заметки, даты создания/изменения |
| 🎲 **Генератор паролей** | Настраиваемая длина, набор символов, исключение похожих |
| 🔍 **Поиск** | Мгновенная фильтрация по названию, логину, URL |
| 📤 **Экспорт / Импорт** | Поддержка JSON, CSV, XML (с шифрованием или без) |
| 🔢 **TOTP (2FA)** | Отображение и копирование одноразовых кодов |
| ⏰ **Автоблокировка** | По бездействию (настраиваемый таймаут) |
| 🔄 **Смена мастер-пароля** | Автоматическое перешифрование всех данных |
| 🌗 **Две темы** | Светлая и тёмная (премиум-дизайн) |
| 🖥️ **Системный трей** | Сворачивание в фон |
| 💾 **Резервное копирование** | Автоматическое при каждом изменении (последние 10 копий) |

## 🚀 Быстрый старт

### 1. Проверьте версию Python
```bash
python3 --version
```

Требуется **Python 3.10 или новее**.

### 2. Клонируйте репозиторий

```
git clone https://github.com/Shavermushka/LockBox2.git
cd LockBox2
```


### 3. Проверьте версию Python

```
python3 --version
```

Требуется **Python 3.10 или новее**.

### 4. Создайте виртуальное окружение

```
python3 -m venv venv
```

### 5. Активируйте его

- **Linux / macOS**:

```
source venv/bin/activate
```
- **Windows (cmd)**:

```
venv\Scripts\activate.bat
```
- **Windows (PowerShell)**:

```
venv\Scripts\Activate.ps1
```

### 6. Установите зависимости

```
pip install -r requirements.txt
```

### 7. Запустите приложение

```
python main.py
```

> **При первом запуске** будет предложено создать мастер-пароль – **запомните его!** Восстановление невозможно.

## 🖥️ Интерфейс и управление

- **➕ Добавить** – новая запись (или `Ctrl+N`).
- **✏️ Редактировать** – двойной клик по строке.
- **🗑️ Удалить** – выделите запись и нажмите кнопку (или `Delete`).
- **🔍 Поиск** – строка вверху фильтрует по названию, логину, URL.
- **📋 Копирование** – правой кнопкой мыши по записи: скопировать логин, пароль или TOTP-код.
- **🎲 Генератор пароля** – доступен в диалоге редактирования.

---

## ⚙️ Настройки

- **Автоблокировка**: таймаут бездействия в секундах (0 – отключить).
- **Резервные копии**: создаются в `~/.lockbox_pro/backups/` (автоматически, но можно отключить).

## ❓ Часто задаваемые вопросы

**Что делать, если забыл мастер-пароль?**
Ничего. Данные невосстановимы – это сделано намеренно для вашей безопасности.

**Можно ли импортировать из KeePass?**
Да, через экспорт из KeePass в CSV/JSON и импорт в LockBox2

**Безопасно ли хранить TOTP-секреты вместе с паролями?**
Да, так как вся база шифруется мастер-паролем. Это удобно для быстрого копирования кодов, но не заменяет отдельный аутентификатор.
